A program that writes one line to `/output/entry.txt` — a museum placard for the office stapler, recast as a ritual binding device of the Filing Clerks — for [Office Artifacts: The One-Line Placard Contest](https://make.fun/bounty/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2) on make.fun. A dry-witted curator judge reads the placards two at a time and keeps the more inventive and funnier one.

## The line

> Stapler, c. 1998. Steel, rust, and quiet menace. Ritual binding device of the Filing Clerks; donor unknown, victim count unrecorded.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (within the 1–180 gate) and nothing else.

## Layout

- `main.py` — the entry program: writes the stapler placard to `entry.txt`.
